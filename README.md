## 简介

一个用于预览「VASH」痛包痛窗（ita-bag window）排版效果的单页工具：

- 多图层：添加任意多张图片（点击多选 / 拖入 / Ctrl+V 粘贴），每张图片为一个独立图层
- 模板图形（矩形 / 圆形）：左侧「制作模板图形」或图层行的 ✎ 打开独立子页面。新建时自动
  载入选中的图片图层作为素材（也可在下拉更换来源或上传新图片），自定义形状、尺寸（矩形
  宽高 / 圆形半径）及内部图片的位置 / 宽度 / 旋转（子页面内拖动移动、滚轮缩放），预览即
  最终裁剪效果；保存后成为模板图层，来源图层自动隐藏（👁 可恢复），主页面仅显示裁剪后
  的图形。主页面上模板只能移动和旋转（拖动 / 旋转握把 / 双指平移），不能缩放；随时可回
  子页面调整，保存后主页面即时同步
- 图层面板（右侧，PS 风格）：缩略图列表自上而下 = 自前景到背景，支持选中、显示/隐藏、
  重命名（双击）、拖动排序、置顶/上移/下移/置底、复制、删除、清空；画布上点击可直接
  选中该处最上层的图片
- 每图层独立变换：宽度（cm）、水平/垂直偏移、旋转（滑块/输入/90° 按钮）、水平与垂直翻转；
  画布上可直接操控选中图层——拖动移动、拖四角缩放（对角固定）、拖选框上方圆柄旋转
  （Shift 吸附 15°）、滚轮以鼠标为中心缩放、双指开合缩放、方向键微调
- 快速对齐（作用于选中图层）：铺满痛板 / 铺满可视区 / 完整显示 / 居中 / 还原（恢复为添加时的宽度）
- 三种模式：全展开（可视高 15.5cm）、半遮挡（12cm）、并排对比
- 痛板底色、多种配色方案、VX21 加强筋、遮挡不透明度、参考线
- 导出：痛板图（按图层顺序合成）/ 预览图，PNG/JPG，150–600 DPI，出血设置
- 包型预览器切换：工具栏最左侧可选择痛包预览器。当前支持「VASH 痛窗」与「自定义包型」
  两种；自定义包型通过「⚙ 包型设置」子页面配置**痛板长宽**、**包体大小**与**痛板图片**
  （铺满/完整显示/居中、偏移与旋转、拖拽微调），痛板图片垫在痛板后方构成包体背景，与图片 /
  模板的自定义完全独立，配置持久化保存；该模式下隐藏包体配色 / 加强筋 / 遮挡等 VASH 专属
  控件，导出预览图包含背景，导出痛板图仅含痛板
- 照片透视矫正：自定义包型中上传斜拍照片后，可框选「包体四边形」与「痛板四边形」，
  单应变换自动拉正，使背景精确贴合包体与痛板边缘（含痛板建议线、实时矫正预览、
  凸性/包含校验、缩放平移）
- 浅色 / 深色模式：工具栏「☀️ 浅色 / 🌙 深色」一键切换，画布配色同步适配，选择保存在本地
- 自定义尺寸：窗口层、可视区、痛板、痛包宽高等

页面为自包含单文件 `index.html`（内联 CSS/JS），仅外链 Google Fonts（离线时自动回退到系统字体）。

## 使用

直接用浏览器打开 `index.html` 即可，无需构建、无需服务器：

```
start index.html
```

或启动本地服务器访问：

```
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/
```
